# VIP Box Game

Un juego interactivo construido con React, Next.js, Three.js y react-moveable.

## Objetivo
Arrastra la caja "VIP" dorada para evitar colisionar con los meteoritos rojos durante 30 segundos. El objetivo es mantener el número de colisiones al mínimo.

## Tecnologías Utilizadas
- **Next.js / React**
- **Three.js & React Three Fiber** para el fondo inmersivo.
- **react-moveable** para el arrastre fluido del elemento VIP dentro del DOM.
- **TailwindCSS** para el diseño de la interfaz premium.

## Instalación y Ejecución
1. Instala las dependencias:
   ```bash
   npm install
   ```
2. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
3. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
